## From preview to composition

Browse and preview Elements right here, then add them to your own Remotion project. There is no need to download this website or run it locally. Each Element installs as an editable TSX file, not a runtime library.

1. Open your Remotion project in **Studio** and select the composition you want to work on.
2. Choose an [Element](/) on this site and try its preview settings.
3. Click **Install in Studio**, or drag **Drag to Studio** onto your Studio canvas. On a touch device, use **Install in Studio**.
4. **Review and confirm in Studio.** “Awaiting confirmation” means the request arrived, not that installation has completed.
5. Select the installed Element to adjust its audio, size, colors, transforms and timing.

Installation uses the Element’s original source defaults, not your preview changes. To reuse preview settings, expand **Use these settings in code** and choose **Copy configured JSX**.

### If Studio is not found

Keep your intended Studio open and focused before sending the request. Check that it uses a compatible Remotion version, runs on a port between **3000 and 3009**, and that your browser allows local-network access when prompted. Tested with **Remotion 4.0.520**, React 19.1.1 and aligned `@remotion/*` versions. You can also [download the source](#download-instead) if the connection is unavailable.

## Add the collection to Studio

Use **Add Library to Studio** at the bottom of a page. Confirm in Studio and restart it to load the collection in Browse Elements. Keep this import in `remotion.config.ts` so the protocol can append a working call:

```ts
import { Config } from "@remotion/cli/config";
```

## Audio setup

No props are required: `audioSrc` defaults to Remotion’s hosted example audio. Choose an asset with the Studio control, or supply an HTTPS URL that allows CORS. For an asset in your own Remotion project's `public/` directory:

```tsx
import { staticFile } from "remotion";
import { Waveform } from "./waveform.element";

export const MyComposition = () => (
	<Waveform
		audioSrc={staticFile("my-track.mp3")}
		audioOffsetInSeconds={12}
		width={900}
		height={300}
	/>
);
```

Use audio you have permission to use. No user-provided audio or artwork is distributed by this site.

- `playAudio` defaults to `true`. Enable it on **only one Element** when stacking instances on the same track.
- `inputGainDb` controls analysis gain, **not playback volume**.
- Analysis uses the first channel; playback preserves the source channels.
- `audioOffsetInSeconds` selects source time and is rounded to the nearest composition frame. Moving an Element does not change that offset; trimming advances local source time.
- Analysis uses fixed 60 Hz timing and 20-second decode chunks. Elements wait for complete neighboring windows and decode independently. More instances cost more memory.
- Silence follows the end of the source; procedural shader motion may continue.

## Timing and sizing

Every Element owns its Sequence. **Do not wrap it in another `<Sequence>`**: selecting the outer Sequence would show its controls instead of the Element schema. Use the Element’s Studio timing controls.

Insertion starts at **480 frames**; its duration in seconds depends on the target FPS. Site previews are 960 frames at 60 FPS. Use `width` and `height` for drawing bounds and Studio transforms for positioning or scaling.

## Download instead

Download the TSX from an Element page into your Remotion source directory and import its named component. The file uses only external imports: React, Remotion, `@remotion/media` and `@remotion/media-utils`. Install those packages in your own project, keeping all `@remotion/*` versions aligned with your Remotion version.

## Rendering with ANGLE

WebGL2 Elements may require **ANGLE** when rendering with Remotion, depending on your system and graphics environment. If an Element previews correctly but renders blank or reports a WebGL error, try adding `--gl=angle` to your render command:

```bash
npx remotion render src/index.ts MyComposition out/video.mp4 --gl=angle
```

Replace the entry point, composition ID and output path with those from your project. This selects Chromium’s ANGLE graphics backend; it is not required for the SVG-only Waveform and Oscilloscope Elements. Graphics support still depends on the rendering environment.

## Renderer compatibility

Waveform and Oscilloscope use SVG. Spectre, Circle, Pulsar, Halo, Audio Particles and Ferrofluid require WebGL2 with graphics acceleration. Unsupported shaders report failure rather than switching to a different visual. Avoid running many WebGL previews at once.

Halo, Audio Particles and [Ferrofluid](/ferrofluid.html) are experimental.
