## Install an Element

Preview Elements on this site, then add them to your own Remotion project. Each Element installs as a TSX file you can edit, not as a runtime library.

1. Open your Remotion project in Studio and select the composition you want to work on.
2. Choose an [Element](/) on this site and adjust its preview settings.
3. Click **Install in Studio**, or drag **Drag to Studio** onto the Studio canvas. On a touch device, use **Install in Studio**.
4. Review and confirm the request in Studio. "Awaiting confirmation" means the request arrived. It does not mean the installation finished.
5. Select the installed Element to adjust its audio, size, colors, transforms and timing.

Install and drag both use your current preview settings. The site writes those settings into the source as its defaults before it sends the file to Studio. After installation you can edit the source or use the Element's Interactive controls in Studio.

Studio can't open browser file URLs, so a local audio or image file needs a hosted URL before you install. **Download TSX** keeps the original defaults. To use a download with your preview settings, expand **Use these settings in code** and choose **Copy configured JSX**.

### If Studio is not found

Keep the Studio you want to use open and focused when you send the request. If the site still can't find it, check that:

- Studio runs Remotion 4.0.536 or later, which supports `Interactive.create()`. We test with Remotion 4.0.547, React 19.3.1 and matching `@remotion/*` versions.
- Studio runs on a port between 3000 and 3009.
- Your browser allows local network access when it asks.

If the connection still fails, [install from the command line](#install-from-the-command-line) or [download the source](#download-instead).

## Install from the command line

With Remotion **4.0.542 or newer**, run [`npx remotion elements use`](https://www.remotion.dev/docs/cli/elements/use) from your Remotion project. You don't need to open Studio.

```bash
npx remotion elements use https://banger-elements.dev/elements/waveform --composition MyComposition
```

Replace the URL with any Element page and `MyComposition` with your composition ID. The CLI shows what it will change before asking for confirmation. Add `--dry-run` to see the plan without writing any files. The CLI installs the Element with its original defaults, not settings from the website preview.

Visualizers and shaders also copy the demo track to `public/banger-elements/`, so a new Element plays offline before you set your own audio. Every Element shares that one file. Rain also copies its texture, `rain.jpg`, to the same folder.

## Add the collection to Studio

Click **Add Library to Studio** in the desktop header or at the bottom of a page. Confirm in Studio, then restart Studio to see the collection in Browse Elements. The install appends a call to `remotion.config.ts`, so keep this import in that file:

```ts
import { Config } from "@remotion/cli/config";
```

With Remotion **4.0.547 or newer**, you can add the collection from your project instead:

```bash
npx remotion elements add-library https://banger-elements.dev
```

The command adds the same `Config.addElementLibrary()` call. If the collection is already in your config, it changes nothing.

## Visualizers, shaders and effects

Visualizers draw your audio as shapes, spectra and particles. Shaders are full-frame procedural backgrounds, such as [Pulse](/elements/pulse), [Cathedral](/elements/cathedral), [Liquid](/elements/liquid) and [Trip](/elements/trip). The [shaders page](/shaders) lists them all.

- Every shader takes `timeOffsetInSeconds`, which sets the animation phase separately from the audio trim. Motion follows the Element's local frame, so use this offset to line up instances that start at different times.
- Shaders with a `bpm` prop use it as the animation tempo, 120 by default. It does not detect beats, and you can't keyframe it as a speed ramp.
- Shaders fill the composition you place them in, at any size or aspect ratio. Pass `width` and `height` to draw one in a fixed box instead.
- Shaders are opaque inside their bounds. Place them behind other Elements, and turn on audio playback for only one layer.
- `inputGainDb` sets how strongly a shader responds to audio. Each shader page lists its other controls. On Trip, for example, `intensity` sets the raymarch iteration count, not the audio gain.
- Shader motion continues through silence and after the audio ends.

### Effects wrap your content

[VHS](/elements/vhs), [Fisheye](/elements/fisheye) and [Wet Glass](/elements/wet-glass) are wrappers. They change only their children, not sibling layers. Install or download one, then move your existing Elements and text inside it in code. Installing does not wrap the layers you have selected in Studio, and the source does not include the site's demo children.

```tsx
import {Fisheye} from './fisheye.element';

<Fisheye width={1280} height={720} strength={0.75} perspectiveFactor={0.35}>
  {/* Your existing Elements and text go here. */}
</Fisheye>
```

Give each child the same drawing size as the wrapper, and use absolute positioning to stack layers. The wrapper has its own Sequence and moves the whole group. Each child keeps its own timing. To bypass the effect, set `strength` to 0, or `amount` on Wet Glass. Effects don't play or analyze audio, so the preview's **Demo audio** controls change only the demo children.

The WebGL path uses Remotion's experimental HTML-in-canvas support to process the group.

- The browser preview needs Chrome 149 or later with `chrome://flags/#canvas-draw-element` turned on.
- Other browsers get deterministic SVG approximations. Wet Glass draws its droplet field on a separate canvas and passes it to the SVG filter. The Fisheye fallback uses the same lens equation through a sampled displacement map, and it can look a little softer near the edges.
- Renders use Remotion's bundled browser and need `--gl=angle` or `--gl=swangle` to take the WebGL path.
- Don't nest one HTML-in-canvas effect inside another.

## Audio setup

Visualizers and shaders need no props. `audioSrc` defaults to Remotion's hosted example audio. When you install from Studio or the command line, the installed Element points at a local copy in `public/banger-elements/` instead. To use your own track, choose an asset with the Studio control or pass an HTTPS URL that allows CORS. For a file in your project's `public/` directory:

```tsx
import { staticFile } from "remotion";
import { Waveform } from "./waveform.element";

export const MyComposition = () => (
	<Waveform
		audioSrc={staticFile("my-track.mp3")}
		audioOffsetInSeconds={12}
		width={900}
		height={300}
	/>
);
```

Use only audio you have permission to use. This site does not distribute any audio or artwork you provide.

- `playAudio` defaults to `true`. When you stack several Elements on the same track, turn it on for only one of them.
- `inputGainDb` sets the analysis gain. It does not change playback volume.
- Analysis reads the first channel. Playback keeps all of the source channels.
- `audioOffsetInSeconds` sets the source time where the Element starts, rounded to the nearest composition frame. Moving an Element on the timeline does not change the offset. Trimming its start moves the source time forward.
- Analysis runs at a fixed 60 Hz and decodes audio in 20-second chunks. Each Element decodes its own chunks and waits until the chunks around the current frame are ready, so more instances use more memory.
- After the source ends, the audio is silent. Shader motion can continue.

## Timing and sizing

Every Element has its own Sequence. Don't wrap an Element in an extra `<Sequence>`. If you do, selecting the outer Sequence in Studio shows the Sequence's controls instead of the Element's. Use the Element's own timing controls in Studio. Effects are the exception, because they contain child Elements that keep their own Sequences.

Studio inserts an Element with a duration of 480 frames, so its length in seconds depends on the composition's frame rate. Site previews last 540 frames at 60 fps. Effect and Audio Particles previews last 960 frames to match the demo track. Visualizers and effects draw in a 1280×720 box by default. Use `width` and `height` to change it, and use Studio transforms to position or scale the Element. Shaders fill the composition unless you pass `width` and `height`.

## Download instead

Download the TSX from an Element page into your Remotion source directory and import its named component. The import path depends on where you save the file. For example, if you save Waveform as `src/elements/waveform.element.tsx`:

```tsx
import { Waveform } from "./elements/waveform.element";

export const MyComposition = () => <Waveform width={900} height={300} />;
```

The downloaded file imports only React, Remotion, `@remotion/media` and `@remotion/media-utils`. Install those packages in your project, and keep every `@remotion/*` package on the same version as Remotion.

## Use with coding agents

Every page on this site has a Markdown version for coding agents such as Claude Code, Codex and Cursor. Add `.md` to the page URL, for example [/halo.md](/elements/halo.md). [/llms.txt](/llms.txt) lists the whole collection, with a one-line description and a link to each Element's Markdown page.

Each Element's Markdown page lists its install command, its props with defaults and ranges, and what to check before you render. Remotion's [`/remotion-elements` skill](https://www.remotion.dev/docs/agents) reads these pages to pick an Element and install it with `npx remotion elements use`.

## Rendering with ANGLE

Some systems need ANGLE to render WebGL2 Elements. If an Element previews correctly but renders blank or reports a WebGL error, add `--gl=angle` to your render command:

```bash
npx remotion render src/index.ts MyComposition out/video.mp4 --gl=angle
```

Replace the entry point, composition ID and output path with your own. The flag switches Chromium to its ANGLE graphics backend. Waveform and Oscilloscope use SVG only and don't need it.

On a machine without a usable GPU, such as CI, a server or WSL, use `--gl=swangle` instead. It renders in software, so it is slower.

## Renderer compatibility

Waveform and Oscilloscope use SVG. Spectre, Circle, Pulsar, Halo, Audio Particles, Ferrofluid and all shaders need WebGL2 with graphics acceleration. If WebGL2 isn't available, a shader reports an error instead of switching to a different visual. Each WebGL preview uses its own GPU context, so avoid running many at once.
