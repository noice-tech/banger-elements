## From preview to composition

Browse and preview Elements right here, then add them to your own Remotion project. Each Element installs as an editable TSX file, not a runtime library.

1. Open your Remotion project in **Studio** and select the composition you want to work on.
2. Choose an [Element](/) on this site and try its preview settings.
3. Click **Install in Studio**, or drag **Drag to Studio** onto your Studio canvas. On a touch device, use **Install in Studio**.
4. **Review and confirm in Studio.** “Awaiting confirmation” means the request arrived, not that installation has completed.
5. Select the installed Element to adjust its audio, size, colors, transforms and timing.

Install and drag use your current preview settings. The website changes the defaults in the source before it sends the source to Studio. Settings that match the source defaults need no changes. You can edit the installed source or use its Interactive controls.

For local audio or image files, use a hosted URL before installation. Browser file URLs do not work in Studio. **Download TSX** keeps the original source defaults. To use that download with your preview settings, expand **Use these settings in code** and choose **Copy configured JSX**.

### If Studio is not found

Keep your intended Studio open and focused before sending the request. Check that it uses a compatible Remotion version, runs on a port between **3000 and 3009**, and that your browser allows local-network access when prompted. Tested with **Remotion 4.0.523**, React 19.1.1 and aligned `@remotion/*` versions. You can also [download the source](#download-instead) if the connection is unavailable.

## Add the collection to Studio

Use **Add Library to Studio** in the desktop header or at the bottom of a page. Confirm in Studio and restart it to load the collection in Browse Elements. Keep this import in `remotion.config.ts` so the protocol can append a working call:

```ts
import { Config } from "@remotion/cli/config";
```

## Visualizers, shaders and effects

**Visualizers** draw your audio as shapes, spectra and particles. **Shaders** are full-frame procedural backgrounds: try [Trip](/trip.html), [Space](/space.html), [Synthwave](/synthwave.html), [Mushrooms](/mushrooms.html), [Fractals](/fractals.html), [Hyperloop](/hyperloop.html), [Downfall](/downfall.html), [Rail](/rail.html), or [Rain](/rain.html).

Trip preserves banger.show's five controls: `baseColor`, `intensifyColor`, `thickness`, `pattern` and `intensity`. Its `intensity` changes the raymarch iteration count, **not audio gain**; fractional values truncate to whole iterations. Use `inputGainDb` for audio response.

- `bpm` sets the animation tempo (default 120). It is not automatic beat detection or a keyframable speed ramp.
- `timeOffsetInSeconds` selects animation phase independently of the audio trim. Motion uses the element's local frame, so use this offset to align separately placed instances.
- Trip is opaque within its bounds. Place it behind other elements and enable audio playback on only one layer.
- The original spherical projection uses a fixed camera; actual width/height determine perspective framing. Higher intensity costs more GPU time. Animation continues in silence and after audio ends.

### Effects wrap your content

[VHS](/vhs.html) and [Fisheye](/fisheye.html) are wrappers, not overlays over sibling layers. Install or download one, then move your existing Elements and text inside it in code. Installation does not automatically wrap selected Studio layers. The site's demo children are not included in the source.

```tsx
import {Fisheye} from './fisheye.element';

<Fisheye width={1280} height={720} strength={0.75} perspectiveFactor={0.35}>
  {/* Your existing Elements and text go here. */}
</Fisheye>
```

Match child drawing dimensions and use absolute positioning to stack layers. Each wrapper owns its Sequence and moves the group; children retain their own timing. Set `strength={0}` for a clean bypass. Effects do not play or analyze audio: the preview's **Demo audio** controls affect only the demo children. The WebGL path uses Remotion’s experimental HTML-in-canvas support to process the group. Browser preview requires Chrome 149+ with `chrome://flags/#canvas-draw-element` enabled. Unsupported browsers use deterministic SVG approximations; the Fisheye fallback follows the same lens equation through a sampled displacement map but may look slightly softer near the edges. Rendering uses Remotion’s bundled browser and requires `--gl=angle` or `--gl=swangle` for the faithful path. Do not nest HTML-in-canvas effects.

## Audio setup

For visualizers and shaders, no props are required: `audioSrc` defaults to Remotion’s hosted example audio. Choose an asset with the Studio control, or supply an HTTPS URL that allows CORS. For an asset in your own Remotion project's `public/` directory:

```tsx
import { staticFile } from "remotion";
import { Waveform } from "./waveform.element";

export const MyComposition = () => (
	<Waveform
		audioSrc={staticFile("my-track.mp3")}
		audioOffsetInSeconds={12}
		width={900}
		height={300}
	/>
);
```

Use audio you have permission to use. No user-provided audio or artwork is distributed by this site.

- `playAudio` defaults to `true`. Enable it on **only one Element** when stacking instances on the same track.
- `inputGainDb` controls analysis gain, **not playback volume**.
- Analysis uses the first channel; playback preserves the source channels.
- `audioOffsetInSeconds` selects source time and is rounded to the nearest composition frame. Moving an Element does not change that offset; trimming advances local source time.
- Analysis uses fixed 60 Hz timing and 20-second decode chunks. Elements wait for complete neighboring windows and decode independently. More instances cost more memory.
- Silence follows the end of the source; procedural shader motion may continue.

## Timing and sizing

Every Element owns its Sequence. VHS intentionally contains child Elements with their own Sequences. Otherwise, **do not add an extra `<Sequence>` around an Element**: selecting the outer Sequence would show its controls instead of the Element schema. Use the Element’s Studio timing controls.

Insertion starts at **480 frames**; its duration in seconds depends on the target FPS. Site previews using the default Remotion track are 540 frames at 60 FPS; Ferrofluid, Halo and particle previews remain 960 frames. Use `width` and `height` for drawing bounds and Studio transforms for positioning or scaling.

## Download instead

Download the TSX from an Element page into your Remotion source directory and import its named component. The import path depends on where you save the file. For example, if you save Waveform as `src/elements/waveform.element.tsx`:

```tsx
import { Waveform } from "./elements/waveform.element";

export const MyComposition = () => <Waveform width={900} height={300} />;
```

The downloaded file uses only external imports: React, Remotion, `@remotion/media` and `@remotion/media-utils`. Install those packages in your own project, keeping all `@remotion/*` versions aligned with your Remotion version.

## Rendering with ANGLE

WebGL2 Elements may require **ANGLE** when rendering with Remotion, depending on your system and graphics environment. If an Element previews correctly but renders blank or reports a WebGL error, try adding `--gl=angle` to your render command:

```bash
npx remotion render src/index.ts MyComposition out/video.mp4 --gl=angle
```

Replace the entry point, composition ID and output path with those from your project. This selects Chromium’s ANGLE graphics backend; it is not required for the SVG-only Waveform and Oscilloscope Elements. Graphics support still depends on the rendering environment.

## Renderer compatibility

Waveform and Oscilloscope use SVG. Spectre, Circle, Pulsar, Halo, Audio Particles, Ferrofluid and all shaders require WebGL2 with graphics acceleration. Unsupported shaders report failure rather than switching to a different visual. Avoid running many WebGL previews at once.
